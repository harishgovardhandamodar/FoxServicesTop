**fox-services-top** is a terminal GPU monitor built for NVIDIA DGX Spark: every GPU, the processes using it and the whole machine on one screen, with history that survives restarts. It runs on any Linux machine with NVIDIA GPUs.

## In v2.0.2

fox-services-top itself is unchanged from v2.0.0. Releases now publish themselves once their checks pass, and each published release is installed and tested on Ubuntu 22.04 and 24.04 (x86_64 and arm), Debian 12 and Rocky Linux 9.

## Install this release

```bash
curl -fsSL https://raw.githubusercontent.com/harishgovardhandamodar/fox-services-top/main/install.sh | bash -s -- --version v2.0.2
```

Without `-s -- --version v2.0.2`, the installer takes the [latest release](https://github.com/harishgovardhandamodar/fox-services-top/releases/latest). Linux on x86_64 or aarch64 with glibc 2.34 or newer (Ubuntu 22.04, Debian 12, RHEL 9 and later), DGX Spark included; WSL 2 runs the Linux build.
